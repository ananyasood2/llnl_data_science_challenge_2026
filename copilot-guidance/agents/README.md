# Specialized Copilot Agent Roles

These role definitions are source-controlled prompts for developer/evaluation
workflows. The deployed FastAPI orchestrator implements the same boundaries.

- `orchestrator.md`: route requests and require deterministic results.
- `viewport-connectivity-analyst.md`: analyze the current filtered XYZ scope.
- `ct-evidence-analyst.md`: request existing raw-CT evidence for a selection.
- `defect-interpreter.md`: explain recorded rules and caveats only.
- `report-generator.md`: build derivative, viewport-scoped reports.
